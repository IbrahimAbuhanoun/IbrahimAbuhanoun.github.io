Project 1: Controlling Three LEDs with a Potentiometer

Created a 3-LED system that is powered based on the analog pin reading associated with the potentiometer (0–1023).

Demonstration of a 3-LED system responding to potentiometer inputs

Project 2: Controlling Components Using Push Buttons

Used push-button inputs to control two different systems: LED brightness with an audible buzzer at its limits, and the speed and direction of a DC motor.

Demonstration of LED brightness being controlled with push buttons. A passive buzzer is sounded when the brightness reaches a limit

Demonstration of DC motor speed and spinning direction being controlled with push buttons

Project 3: Controlling Servo Motor with a Photoresistor

Controlled a servo horn from 0° to 45° by mapping the photoresistor's analog reading (0–800) to the servo angle, with 800 representing the maximum light level measured under the test conditions.

Demonstration of a servo motor being controlled by a photoresistor. The light is obstrcuted when the resistor is covered

Project 4: Controlling Components Using a Tilt Switch

Used a tilt switch to control the power of a 2-LED inidcation system and a the power output of a DC motor.

Demonstration of a 2-LED system indicating whether the circuit board is tilted or not

Demonstration of how a DC motor's action is influenced by the tilt switch

Project 5: Controlling DC Motor Using a Joystick

Controlled the speed and the spinning direction of a DC motor using an analog joystick.

Demonstration of DC motor speed and spinning direction being controlled by an analog joystick

Project 6: Creating an 8-Bit Binary Display Using LEDs

Created an 8-bit binary display composed of 8 LEDs, which are powered and controlled through a serial-to-parallel shift register.

Demonstartion of an 8-bit binary display using LEDs. The binary manupilation seen is bitwise inversion

Project 7: Creating a Simple Calculator Using an LCD Display

Created a simple calculator that receives user input through serial communication and displays the calculation and result on an LCD display.

Demonstration of an LCD display simulating a simple calculator. The system supports basic operations (+,-,*,/)
